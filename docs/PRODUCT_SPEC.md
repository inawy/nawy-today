# Nawy Today — مواصفات المنتج (1.0)

> **يومك بطريقتك.** · Your day, your way.

تقويم شخصي، سريع، خصوصي. يعمل بلا إنترنت. بياناتك على جهازك فقط.
الأسماء والقرارات التفصيلية في [DECISIONS.md](./DECISIONS.md).

## 1. المبادئ
1. **الصدق:** لا ميزة في الواجهة لا نستطيع الوفاء بها (لذلك لا تذكيرات في 1.0).
2. **السرعة:** إنشاء حدث في أقل من 3 نقرات. الفتح الأول ≤ 1 ثانية على جهاز متوسط.
3. **الخصوصية:** لا حسابات ولا تتبع ولا موارد خارجية.
4. **الأمان من الضياع:** التصدير والنسخ الاحتياطي واللقطات والاسترداد جزء من المنتج، لا إضافة.
5. **عربي أولًا:** RTL حقيقي (وحدات منطقية)، لا قلب شكلي.
6. **موبايل أولًا:** على الهاتف التجربة الأساسية هي **Today** لا شبكة الشهر.

## 3. الشاشات

### 3.1 الإطار العام (Shell)
- **شريط علوي:** زر القائمة · زر "اليوم" · سهما السابق/التالي · عنوان الفترة · مبدّل العرض · بحث · الإعدادات.
- **ديسكتوب (≥ 1024px):** شريط جانبي دائم قابل للطي: زر إنشاء · mini-month · قائمة التقويمات بألوانها.
- **موبايل:** الشريط الجانبي ينزلق كدرج (drawer). زر "+" عائم. الفتح الأول على **Today**.

### 3.2 Today (جدول أعمال)
قائمة عمودية لأحداث اليوم مرتبة بالوقت، طوال اليوم أولًا، مع مؤشر "الآن" وفاصل لما انتهى. تمرير أفقي بين الأيام (أو أسهم). هي الشاشة الرئيسية على الهاتف.

### 3.3 يوم / أسبوع
شبكة وقت بخطوط ساعة، صف طوال اليوم في الأعلى، خط "الآن" أحمر، أحداث متجاورة تُوزَّع في أعمدة عند التراكب (خوارزمية نقية في `core/layout`). على الهاتف عرض أسبوع ثابت أيام مصغرة.

### 3.4 شهر
شبكة 6×7، أحداث كشرائط، "+N أخرى" يفتح اليوم، شرائط الأحداث متعددة الأيام تمتد عبر الأعمدة. النقر على يوم ينتقل لعرض اليوم.

### 3.5 إنشاء/تحرير حدث
- **سريع:** نقر على خانة وقت/يوم يفتح بطاقة صغيرة: عنوان + وقت + تقويم + "مزيد من الخيارات".
- **كامل (ورقة كاملة على الهاتف):** عنوان، طوال اليوم، بداية/نهاية، المنطقة الزمنية، التكرار، التقويم/اللون، الموقع، الملاحظات.
- زر الرجوع **يحفظ ويغلق** (لا زر "تم")، ومؤشر "تم الحفظ"، وتراجع 5 ثوانٍ بعد الحذف.
- عند الفشل في الحفظ: يبقى المحرر مفتوحًا مع رسالة واضحة وإعادة محاولة.
- تحرير حدث متكرر: "هذا الحدث فقط / هذا وما بعده / كل الأحداث".

### 3.6 البحث
نتائج حية مرتبة بالقرب من اليوم، والنقر يفتح الحدث.

### 3.7 الإعدادات
اللغة، المظهر، بداية الأسبوع، 12/24 ساعة، الهجري الثانوي، نوع الأرقام، العرض عند الفتح (D-054). قسم **البيانات**: تصدير، استيراد (بمعاينة)، اللقطات والاسترداد، حالة التخزين الدائم.

## 4. نموذج البيانات

```ts
type Calendar = {
  id: string;            // UUID
  name: string;
  color: string;         // token id أو hex
  visible: boolean;
  createdAt: number; updatedAt: number;
  deletedAt?: number;    // tombstone
};

type CalEvent = {
  id: string;            // UUID
  calendarId: string;
  title: string;
  notes?: string;
  location?: string;     // نص فقط في 1.0
  allDay: boolean;
  start: string;         // 'YYYY-MM-DDTHH:mm' محلي  | 'YYYY-MM-DD' لطوال اليوم
  end: string;           // حصري لطوال اليوم
  tzid?: string;         // IANA، لغير طوال اليوم
  rrule?: string;        // نص RFC 5545 (مجموعة جزئية)
  exdates?: string[];
  seriesId?: string;     // لسجل override
  originalStart?: string;
  color?: string;        // يتجاوز لون التقويم
  createdAt: number; updatedAt: number;
  deletedAt?: number;
};
```
حقول المزامنة (UUID/updatedAt/deletedAt) موجودة من اليوم رغم عدم وجود مزامنة.

## 5. معايير القبول العامة
- يعمل بلا إنترنت بعد أول زيارة (اختبار e2e بقطع الشبكة).
- لا نص خبيث ينفَّذ (e2e).
- تصدير ثم استيراد يعيد البيانات مطابقة (اختبار رحلة كاملة).
- لا شاشة بيضاء: كل بطاقة/حدث يُرسم داخل حدّ أخطاء بديل.
- ميزانية أداء: 5000 حدث، فتح الشهر ≤ 300ms للرسم الأول، البحث ≤ 200ms.
- تباين ألوان WCAG AA، تنقل بالكيبورد، إدارة تركيز في الحوارات.

## 6. ما نفعله عمدًا بشكل مختلف عن Google Calendar
تقويم أصغر وأسرع وأكثر خصوصية، وToday هي الشاشة الأولى على الهاتف، والنسخ الاحتياطي ظاهر، ولا شيء مخادع.
